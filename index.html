02

GrocerGenius: AI-Based Supermarket Sales Prediction

A predictive analytics machine learning application developed during the Infosys Springboard Internship 5.0 to forecast retail sales trends using structured supermarket data and gradient-boosted trees.

Problem Statement

Supermarkets handle hundreds of product categories across diverse outlets. Inaccurate demand estimation results in inventory spoilage or lost revenue.

Proposed Solution

An end-to-end ML pipeline with rigorous data preprocessing, categorical encoding, and an optimized XGBoost regression model deployed via an interactive Streamlit UI.

Key Technical Highlights:

  • Data cleaning, imputation of missing store values, and outlier mitigation
  • Categorical feature encoding using OneHotEncoder and Leave-One-Out Encoding
  • XGBoost regressor training, hyperparameter tuning, and cross-validation
  • Artifact persistence using Joblib for rapid prediction serving
  • Interactive Streamlit UI allowing store managers to simulate item and outlet parameters

Technology Stack:

Python Pandas Scikit-learn XGBoost Streamlit Joblib OneHotEncoder Leave-One-Out Encoding

My Technical Contributions:

Authored feature engineering scripts, performed exploratory data analysis (EDA), evaluated encoding strategies for high-cardinality features, integrated the trained model into Streamlit, and serialized artifacts with Joblib.
